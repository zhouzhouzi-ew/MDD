# fMRI-EEG 产妇抑郁判断汇报界面设计

## 目标

将现有“只基于生理指标的预测页面”收敛为辅助分析模块。新的首页围绕“基于 fMRI 和 EEG 的产妇抑郁判断”展开，面向医院方和科研导师说明：研究问题是什么、已有工作覆盖了哪些角度、当前证据是否充分、效果如何、拿到真实 fMRI/EEG 后如何接入联合分析。

## 信息架构

页面采用侧边栏导航：

- 总览：展示研究目标、数据/模型工作链条、当前证据强度和关键风险。
- 联合分析结果：作为主任务入口。当前没有真实 fMRI/EEG 联合结果，因此只展示待接入状态、将输出的指标、临床解释维度和分析流程。
- EEG 预训练：展示 EEG_pretrain 中已完成的路线B源空间工作、消融对比和 held-out 风险提示。路线A只作为历史对照/风险提示，不作为主展示模块。
- 生理指标辅助分析：承接现有页面，但外层只显示最关键结论，详细表格和图表通过 tabs/expander 展开。

## 四层代码结构

所有 Python 文件控制在 500 行以内。代码按四层拆分：

- 配置/领域层：路径、基线定义、展示常量和轻量数据类。
- 数据访问层：读取 CSV、JSON、PNG 资产，处理缺失文件。
- 服务层：计算 lift、方法胜负、最佳行、词云数据、预训练摘要等 view model。
- 展示层：Streamlit 页面与 Plotly 图表分离，`app.py` 只负责启动和路由。

## 可视化原则

首页避免把大量技术图表直接堆满，先给决策者可读的总览。详细信息通过悬停、tab、expander 和跳转式导航展开。

生理指标模块增加更丰富的表达：

- 关键 KPI 卡：阳性样本规模、最佳 PR-AUC/ROC-AUC、SCM vs Linear。
- 提升总览：PR-AUC/ROC-AUC 相对基线提升。
- 方法差值：SCM - Linear 的直接差值。
- 指标词云式图：从最佳组合中抽取高频指标，用文字大小和颜色表示出现次数。
- 定义/方法/指标数热力图：快速看哪些组合更有效。
- PCA 分布与临床达标线：放在详细页签中。

预训练模块展示：

- 路线B源空间流程：Brainstorm/wMNE -> Schaefer100 -> PEC -> GNN encoder。
- 已完成产物：encoder、图数据、结果图。
- 消融对比：dense/topk、fusion、特征版本等。
- 严谨结论：held-out/test 表现接近或低于机会线时要明确提示，不能把交叉验证高值当作临床可用证据。

## 验证

新增自动化测试覆盖数据处理和架构约束：生理结果 lift 计算、词云数据、预训练摘要读取、文件行数上限。最后运行测试和 Streamlit 脚本导入检查。
